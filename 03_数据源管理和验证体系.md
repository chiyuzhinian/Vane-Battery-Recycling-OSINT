### 2.2 验证算法实现

#### **质量评分计算（伪代码）**

```python
def calculate_quality_score(data_item):
    """
    多维度质量评分算法
    
    Args:
        data_item: {
            'value': '格林美产能8万吨',
            'sources': [
                {'name': '知乎', 'credibility': 65, 'url': '...'},
                {'name': '北极星', 'credibility': 85, 'url': '...'},
                {'name': '官方公告', 'credibility': 100, 'url': '...'}
            ],
            'publish_date': '2024-01-10'
        }
    
    Returns:
        quality_score (0-100)
    """
    
    score = 50  # 基础分
    
    # 第一层：来源权威性 (max +30)
    best_source_credibility = max([s['credibility'] for s in data_item['sources']])
    if best_source_credibility >= 95:
        score += 30
    elif best_source_credibility >= 80:
        score += 20
    elif best_source_credibility >= 70:
        score += 10
    
    # 第二层：多源交叉验证 (max +20)
    independent_sources = len(set([s['name'] for s in data_item['sources']]))
    if independent_sources >= 3:
        score += 20
    elif independent_sources == 2:
        score += 15
    elif independent_sources == 1:
        score += 0
        # 标记为"单源"，需审核
        data_item['flags'].append('single_source')
    
    # 第三层：AI逻辑检查 (max +15)
    if check_logic_consistency(data_item['value']):  # Claude API调用
        score += 15
    else:
        score -= 10
        data_item['flags'].append('logic_inconsistency')
    
    # 第四层：时效性 (max +10)
    days_old = (datetime.now() - data_item['publish_date']).days
    if days_old <= 30:
        score += 10
    elif days_old <= 90:
        score += 5
    elif days_old > 180:
        score -= 5
    
    # 第五层：溯源性 (max +5)
    if all(s['url'] for s in data_item['sources']):
        score += 5
    elif any(s['url'] for s in data_item['sources']):
        score += 2
    else:
        score -= 10
        data_item['flags'].append('no_source_url')
    
    # 确保分数在0-100范围内
    return max(0, min(100, score))
```

## 第三部分：数据质量评估和审核

### 3.1 质量等级定义

```
┌─────────────────────────────────────────────────────────────────┐
│                    数据质量等级体系                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│ 🟢 等级A（高置信 >= 80分）                                     │
│   ────────────────────────────────────────                     │
│   特征：                                                        │
│     ✓ 来自官方权威源或多个行业权威源                            │
│     ✓ 至少2个独立来源确认                                       │
│     ✓ AI逻辑检查通过                                            │
│     ✓ 信息新鲜度好 (< 90天)                                     │
│     ✓ 完整溯源链接                                              │
│                                                                 │
│   处理方式：                                                    │
│     → 直接入库，无需人工审核                                    │
│     → 可用于决策和对外引用                                      │
│     → 标记为"已验证"                                            │
│                                                                 │
│   示例：                                                        │
│     格林美2024年产能目标8万吨                                   │
│     (来源：官方公告+年报+新闻，质量分数：92)                    │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│ 🟡 等级B（中置信 60-79分）                                     │
│   ────────────────────────────────────────                     │
│   特征：                                                        │
│     ✓ 来自单一官方源或多个可信行业源                            │
│     ✓ 单个或部分来源确认                                        │
│     ✓ AI逻辑检查基本通过                                        │
│     ✓ 信息相对新鲜但有些陈旧                                    │
│     ✓ 有部分溯源信息                                            │
│                                                                 │
│   处理方式：                                                    │
│     → 加入"待审核队列"                                          │
│     → 由人工审核员进行确认                                      │
│     → 审核通过后入库                                            │
│     → 标记为"人工审核通过"                                      │
│     → 可用但需注明数据来源级别                                  │
│                                                                 │
│   示例：                                                        │
│     邦普循环2024年产能规划                                      │
│     (来源：新闻报道，质量分数：72)                              │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│ 🔴 等级C（低置信 < 60分）                                      │
│   ────────────────────────────────────────                     │
│   特征：                                                        │
│     ✓ 单一非官方来源或来源可信度低                              │

│                                                                 │
│   处理方式：                                                    │
│     → 需要"强制人工审核"                                        │
│     → 审核员调查和验证                                          │

│                                                                 │
│   示例：                                                        │

│     (质量分数：45)                                              │

```

## 第四部分：动态数据源更新机制

### 4.1 自动学习和调整

#### **源权重自动调整算法**

```python
def auto_adjust_source_weight(source_id, recent_validations):
    """
    根据最近100条验证结果自动调整源权重
    
    recent_validations: [
        {'quality_score': 85, 'timestamp': '...'},
        {'quality_score': 92, 'timestamp': '...'},
        ...
    ]
    """
    
    # 计算该源的平均质量评分
    avg_score = sum(v['quality_score'] for v in recent_validations) / len(recent_validations)
    
    # 获取当前源配置
    current_weight = get_source_weight(source_id)
    
    # 权重调整规则
    if avg_score >= 90:
        # 优秀源：提高权重和优先级
        new_weight = current_weight * 1.2
        auto_promote_priority(source_id)
    elif avg_score >= 80:
        # 良好源：保持或略微提高
        new_weight = current_weight * 1.05
    elif avg_score >= 70:
        # 可靠源：保持不变
        new_weight = current_weight
    elif avg_score >= 60:
        # 不稳定源：降低权重
        new_weight = current_weight * 0.85
        log_warning(f"Source {source_id} quality declining")
    else:
        # 问题源：标记为可能不可用
        new_weight = current_weight * 0.5
        flag_source_for_review(source_id)
    
    # 更新源配置
    update_source_weight(source_id, new_weight)
    
    return new_weight
```

## 第五部分：数据质量监控和告警

### 5.1 监控指标

```
关键指标体系：

1. 数据入库率 (Data Ingestion Rate)
   - 目标：每日采集数据 > 100条
   - 告警：< 50条/天

2. 高质量数据比例 (High-quality Data %
   - 目标：>= 70% 数据为A/B级
   - 告警：< 50%

3. 验证成功率 (Verification Success Rate)
   - 目标：>= 85% 数据通过验证
   - 告警：< 70%

4. 源可用性 (Source Availability)
   - 目标：>= 90% 的源正常工作
   - 告警：< 80%

5. 数据矛盾率 (Data Conflict Rate)
   - 目标：< 5% 的数据有矛盾
   - 告警：> 10%

6. 平均质量评分 (Average Quality Score)
   - 目标：>= 75分
   - 告警：< 60分
```
